# ProHealth Floripa

Scaffold inicial em Next.js, TypeScript e App Router.

## Desenvolvimento local

```bash
npm install
npm run dev
```

Acesse [http://localhost:3000](http://localhost:3000). O endpoint de saúde está disponível em `GET /api/health`.

## Verificação

```bash
npm run lint
npm run build
```

## Deploy na Vercel

Importe este repositório na Vercel, mantenha as configurações detectadas para Next.js e inicie o deploy. Nenhuma variável de ambiente é necessária neste scaffold.
